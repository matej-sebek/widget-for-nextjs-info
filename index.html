Aplikace umožňuje zobrazovat tři nejnovější příspěvky z připojeného profesionálního instagramového účtu na webu, pro který vlastník účtu připojení povolil.

Jaká data aplikace používá

Aplikace zpracovává identifikátor připojeného účtu a přístupový token. Prostřednictvím Meta API načítá identifikátory příspěvků, typ média, adresy obrázků nebo náhledů, odkazy na příspěvky a čas zveřejnění. Pro výběr posledních tří příspěvků může načíst údaje až o dvanácti příspěvcích, včetně údajů o médiích v albech.

Tyto údaje slouží k načtení, výběru a zobrazení příspěvků a k provozu jejich mezipaměti. Přístupový token je uložen pouze na serveru a není zpřístupněn návštěvníkům webu. Aplikace nepožaduje ani neukládá instagramové heslo.

Aplikace nečte soukromé zprávy, komentáře ani statistiky a nezveřejňuje ani neupravuje příspěvky. Oprávnění ke zprávám obsažené v aktuální konfiguraci nepoužívá.

Hosting a mezipaměť

Pro provoz webové integrace využíváme hosting Vercel. Načtená data a obrázky se dočasně ukládají do mezipaměti kvůli rychlosti a omezení požadavků na Meta API. Obnovení dat nemusí znamenat okamžité odstranění všech starších kopií z mezipaměti. Přístupové údaje jsou uchovávány po dobu aktivního připojení účtu.

Tyto informační stránky jsou hostované na GitHub Pages. GitHub při jejich návštěvě zaznamenává IP adresu pro bezpečnostní účely. Další informace uvádí zásady ochrany soukromí GitHubu.
