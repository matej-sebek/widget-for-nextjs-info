# widget-for-nextjs-info

Veřejné informační stránky Meta aplikace **widget-for-nextjs**, která slouží ke zobrazení tří nejnovějších příspěvků z připojeného profesionálního instagramového účtu na webu.

## Stránky pro nastavení Meta aplikace

Po zapnutí GitHub Pages lze do nastavení aplikace vložit tyto adresy:

| Pole v Meta dashboardu | Adresa |
| --- | --- |
| Privacy policy URL | https://matej-sebek.github.io/widget-for-nextjs-info/ |
| User data deletion → Data deletion instructions URL | https://matej-sebek.github.io/widget-for-nextjs-info/data-deletion.html |

## Obsah repozitáře

- `index.html` — ochrana soukromí a informace o zpracovávaných údajích.
- `data-deletion.html` — postup pro odpojení účtu a žádost o smazání dat.
- `styles.css` — společný vzhled obou stránek.

Jde o statické HTML a CSS. Není potřeba instalace závislostí ani sestavení projektu. Kód instagramové galerie a její serverová konfigurace jsou součástí webu, který integraci používá.

## Zveřejnění přes GitHub Pages

V repozitáři otevři **Settings → Pages** a nastav:

- **Source:** Deploy from a branch
- **Branch:** main
- **Folder:** / (root)

Změny ulož tlačítkem **Save**. Další změny v této větvi GitHub Pages automaticky zveřejní.
